# Profile setup — step by step

Two things live in this folder:

1. `README.md` + `.github/` → your **dynamic profile README**
2. `set-repo-metadata.sh` → sets **descriptions + topics** on all 10 repos in one go

---

## 1 · Publish the profile README

GitHub shows a special repo named exactly after your username at the top of your profile.

```bash
# from inside this folder
git init
git add README.md .github
git commit -m "Add dynamic profile README"
git branch -M main

# create the special repo (must be public, named EXACTLY "Diabloansh")
# either on github.com/new, or with the gh CLI:
gh repo create Diabloansh --public --source=. --remote=origin --push
```

If you're not using `gh`, create `Diabloansh/Diabloansh` on github.com first, then:

```bash
git remote add origin https://github.com/Diabloansh/Diabloansh.git
git push -u origin main
```

### Turn on the contribution snake 🐍
The snake SVG is generated by the included Action, not committed by you.

1. After the first push, open the repo → **Actions** tab → enable workflows.
2. Run **"Generate contribution snake"** once manually (`workflow_dispatch`).
3. It creates an `output` branch with `snake.svg` / `snake-dark.svg`. The README already points there. It re-runs twice a day.

Until that first run finishes, the snake image will be broken — that's expected.

## 2 · Fix descriptions + topics on all repos

Every widget in the README is live already. The one manual win left is that **6 of 10 repos have no description and none have topics** — which is why they look empty on your profile.

```bash
export GH_TOKEN=ghp_xxx      # a token with `repo` scope: github.com/settings/tokens
bash set-repo-metadata.sh
```

Or, if you have the `gh` CLI authenticated, it works with no token export.

## Notes on the widgets (so you can tweak them)

All colors are pulled straight from anshmadan.com:

| token  | hex       |
|--------|-----------|
| violet | `#7C5CFF` |
| coral  | `#FF5B2E` |
| lime   | `#BEEF3A` |
| ink bg | `#0E0E12` |
| text   | `#F4F2EC` |

- **Header/footer waves** → `capsule-render`
- **Typing line** → `readme-typing-svg` — edit the `lines=` param
- **Stats / streak / top-langs** → `github-readme-stats` + `github-readme-streak-stats`
- **Activity graph** → `github-readme-activity-graph`
- **Trophies** → `github-profile-trophy`
- **Profile views** → `komarev` counter

If any card ever fails to load, it's a rate limit on the shared demo instance — refresh, or self-host `github-readme-stats` on your own Vercel (5-min deploy) and swap the domain.
